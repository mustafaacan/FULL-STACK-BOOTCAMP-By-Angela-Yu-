
EJS --> Templating language

Using EJS is more clear and easy way to manage the frond End activities
than sending files or HTML structures

For instace using res.sendFile(...) provides a static approach

We can use res.render(...) to provide EJS key-value pairs


EJS TAGS

<%= %>  --> output is variable

<% %> --> output is JS executable code  (console.log("Hello") etc.)
CRITICAL POINT: No output will be appear on screen

<%- %> --> render html  (<h1>Hello<h1> etc)

<%# %> --> stop execution usually for the comments


<%- include('<FILENAME.ejs>') %> --> insert another EJS files (will be given as URL)



*** CAUTION : WHEN THE RENDER DATA SENT AS OBJECT, DO NOT USE DATA.KEY, USE KEY DIRECTLY 


WHAT IF ,THERE IS NO ANY DATA ?

for this cases, inside the EJS, we can use locals.<KEYWORD> with if clause

this keyword is a built-in keyword

<%= fruits %>  -->  <% if (locals.fruits) {%> ....



LAYOUT AND PARTIAL TEMPLATE

To use the locale styling css files or images, express static should be used

app.use(express.static(<"public" folder path>));

static files usually deploy under the "public" folder so path for the public folder is enough for the define all static elements
located under the public folder

public/
└── styles/
    └── main.css

On the other hand, for cdn structures, we do not need to use static usage

for partial usage, we can use the structure below
<%- include('<FILENAME.ejs>') %> --> insert another EJS files (will be given as URL)
